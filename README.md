# مصحف القراءات العشر بأدلتها من الشاطبية والدرة

صفحة ويب واحدة (`index.html`) تعرض المصحف في ٦٠٤ صفحة على ترقيم مصحف المدينة، وتظلّل كلمات الفرش؛ بالضغط على الكلمة المظلّلة تظهر قراءاتها وبيت الشاطبية وبيت الدرة، مع بحث داخل المصحف.

لا تحتاج إلى بناء أو اتصال بالإنترنت: افتح `index.html` في المتصفح.
